#  Hyderabad House Price Analysis

##  Project Overview

Hyderabad house price analysis project involving data cleaning, handling missing values, and exploratory data analysis to understand trends in property prices based on features like area, location.

---

##  Dataset Details

* The dataset contains information about house prices in Hyderabad
* Includes features such as:

  * Area
  * Location
  * Price
  * Bedrooms
  * Bathrooms
  * Apartment or Villa
* Missing values were identified and handled appropriately

---

##  Tools & Technologies

* Python 
* Pandas
* NumPy
* Matplotlib / Seaborn
* Jupyter Notebook

---

##  Project Workflow

1. **Data Loading**

   * Imported dataset into Jupyter Notebook

2. **Data Cleaning**

   * Checked for missing values
   * Handled null values using appropriate techniques

3. **Exploratory Data Analysis (EDA)**

   * Analyzed relationships between features
   * Identified trends in house prices

4. **Insights Generation**

   * Observed how factors like area and location influence pricing

---

##  Key Insights

* House prices vary significantly based on location
* Larger area generally leads to higher prices
* Data shows clear patterns useful for future prediction models
